## skill นี้ทำอะไร
 - ช่วยอติวสอบ
 - อ่านสไลด์และสรุป
 - มีแบบฝึกหัด

## การ download 

- windows เปิด cmd หรือ พิม cmd ในช่องค้นหา คำสั่งที่ใช้
  1. สร้าง folder ไว้ที่ desktop หรือ ที่ที่จำได้ว่า file อยู่ไหน
  2. cd your path เช่น ~/Desktop/my-skill 
  3. git clone https://github.com/ArtWarakorn/study-tutor.git

- macOS and Linux เปิด terminal 
  1. สร้าง folder ไว้ที่ desktop หรือ ที่ที่จำได้ว่า file อยู่ไหน
  2. cd your path เช่น ~/Desktop/my-skill 
  3. git clone https://github.com/ArtWarakorn/study-tutor.git

## การให้ skill
 - add skill เข้า AI ที่คุณใช้
 - พิมพ์ /study-tutor ใน chat
